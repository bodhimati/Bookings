# LBC weekly bookings

Bookings for London Buddhist Centre retreats and courses over the next three months, compared with past runs. Updated every Monday morning from Ticket Tailor.

- index.html: the page (GitHub Pages)
- upcoming.csv, curves.csv, health.csv: this week's figures
- refresh.py, history.json, RUNBOOK.md: the script, booking history and instructions used by the Monday task
